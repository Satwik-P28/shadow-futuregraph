# Judge questions

Answers a hostile reader can check in the tree.

## Why Shadow?

The sandbox search looks past the cheapest nominally feasible flight and finds a delay-plus-traffic failure the sticker price does not show. The broker then refuses an exam move that a calendar tool could otherwise perform.

## Why Nemotron?

On a 40-case attack set the generic compiler, with no model, recalled 0/25 hard constraints. Super plus the citation check recalled 18/25 and added 0 false hard constraints. That is the measured role. The public demo does not make that call. Its NYC world is an example fixture.

## Why not just a constraint solver?

The solver is not the product. The unsolved part is getting constraints out of messy text. The demo still cheats that step with `example_world.py`. The attack set shows the cheat does not transfer.

## Why trust it?

You should not trust the model. Proposals that cite missing sources or invented numbers are dropped. Unknown stays unknown. Execution authority is the contract, not the email text. A provider that returns success without the new state is marked `verify_mismatch`, not done.

## Does it actually work?

Inside the two fixtures, yes: the same engine repairs travel and the apartment case, blocks the exam, and reconciles the sandbox. Outside those formulas, the compiler is partial (18/25 on the attack set) and there is no search yet because labels are not executable expressions.

## Isn't 30/30 benchmark gaming?

The local gate is monotone and scripted. Say so. The live pilot is an architecture comparison with unequal inputs. The compiler numbers above are the raw-text result.

## Is it always-on?

It reacts to events you inject or that a connected source would emit. It does not poll. Nothing personal is connected. Restart clears the public process.

## Is it private?

The public demo isolates browser sessions so one visitor cannot read another's plan. That state is still on the server, in memory, and it is synthetic. Live compilation would send record text to Nebius. The demo does not do that.

## What is real?

Sandbox writes only. No calendar, mail, or ticket provider is configured.

## What if the model is wrong?

The verifier drops unsupported hard claims. Ranking and authorization do not use the model's confidence. A wrong label can still miss a constraint. The attack set shows that miss rate.

## What if the API lies?

`test_provider_lie_halts` requires a re-read. A success payload that leaves the old departure time halts. `test_timeout_then_retry_is_idempotent` retries the same key and applies the flight once.
