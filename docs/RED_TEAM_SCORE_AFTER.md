# Strict score after red-team fixes

Scored after session isolation, the compiler split, and the 40-case attack evaluation. A 5 is still reserved for work that would be exceptional in an elite field.

## Technological Implementation: 4/5

Strongest evidence: browser sessions cannot read or reset each other. The generic compiler no longer keyword-licenses the hero. On 40 unseen cases it scores 0/25 without a model and 18/25 with Super plus citation checks, with 0 false hard constraints. Provider lies and timeout-after-commit were already tested and still hold. An unknown event that names a missing variable no longer marks every future unknown.

Strongest objection: the search still evaluates fixture formulas. The compiler does not produce those formulas. `example_world.py` remains a phrase table for the NYC demo, and the single word `friday` over-licenses `c_friday` if that table is pointed at other text.

What prevents a 5: the shipped demo's typed world is still authored, not compiled.

## Design: 3/5

Strongest evidence: the README now says the public demo is a per-browser sandbox, not a private device store, and that the local 30/30 table is a scripted regression.

Strongest objection: the interface is still a two-scenario sandbox. A judge learns the product by clicking "NYC trip," which fills a prepared sentence.

What prevents a 5: the first-run experience does not yet show a constraint the user could not have noticed in the visible fixture.

## Potential Impact: 2/5

Strongest evidence: the delay-plus-traffic failure is a real interaction inside the model, and the broker blocks a plausible wrong write.

Strongest objection: no live calendar, mail, or booking. No user study. Restart drops the demo.

What prevents a 5: nobody has used this on a plan that cost them something.

## Quality of Idea: 4/5

Strongest evidence: semantic proposal, deterministic search, scoped authority, and re-read are separable, and the attack set shows the semantic step is where Nemotron matters.

Strongest objection: until compilation emits an executable world, the idea's middle is a fixture.

What prevents a 5: the fair end-to-end loop on raw text does not exist yet. That blocker is documented in `docs/FAILURE_CASES.md`, not papered over.
